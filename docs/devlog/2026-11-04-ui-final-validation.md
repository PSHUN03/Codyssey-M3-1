# UI 최종 점검 브랜치와 중복 입력 오류 안내 수정

- 관련: FE-03 #16의 공통 검증 후속 수정. 기존 이슈를 재오픈하지 않는다.
- 최신 main `4c15260` 기준으로 `codex/ui-final-polish`를 만들었다. UI 추가 점검용 Draft로 유지한다.
- 공통 `invalid` 처리에서 입력칸 오류가 표시됐는지 확인한 뒤, 표시할 입력칸이 없는 경우에만 폼 전체 오류를 알린다.
- 입력칸 도움말·접근성 연결·첫 오류 포커스, 필수 동의의 폼 안내, 처리 중 상태와 서버 오류 안내는 유지한다. HTML·CSS는 수정하지 않는다.
- [실제 화면과 검증 기록](../qa/UI-final-2026-11-04.md): 브라우저 42개, pytest 101개, Ruff와 기존 AI 품질 평가 통과.
- Codex가 공통 검증 수정과 브라우저 회귀 확인을 도왔다. 변경 범위를 중복 문구에 한정하고, 전체 폼 안내가 필요한 동의·서버 오류·처리 중 상태를 함께 검토했다.
