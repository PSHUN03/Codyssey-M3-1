# FE-02 소비 분석 샘플 화면

- 관련: #15 · FR-14, BE-01 #19, DATA-06 #37
- 브랜치: `codex/FE-02-spending`
- 기존 보라색 목업을 Jinja2·CSS·바닐라 JS로 옮겼다. main·FE-01·FE-04·FE-05에는 push하지 않는다.
- `/plan`의 진입 링크와 `/spending`을 추가했다. 기본 계획 계산은 보존한다.
- 엑셀·CSV 파일 형식/2MB/빈 파일 검사, 샘플 준비 진행 표시, 오류·빈 결과·재시도를 추가했다. 실제 파일은 읽거나 전송하지 않는다.
- 카테고리 차트·상위 지출·고정/변동비는 가상 거래 10건으로 계산한다. 분류 수정이 차트·상위 지출에 즉시 반영된다.
- 사용자가 요청한 분류 메뉴는 기존 내 정보의 흰색 둥근 메뉴·선택 체크·키보드 동작을 재사용했다.
- 페이지 진입과 플랜 복귀는 기존 공통 전환을 유지하고, 차트는 보이면 위에서 아래 순서로 나타난다. 동작 줄이기에서는 정적으로 표시한다.
- [설계 결정과 API 협의 항목](../adr/0012-fe02-spending-sample-preview.md), [QA 및 화면](../qa/FE-02-2026-11-03.md)을 남겼다.
- Codex가 구현과 검사를 도왔다. 샘플과 실데이터 처리의 구분, 키보드 선택·차트 재계산·파일 미전송, 기존 계산 동작을 점검했다. 실제 API·실기기 검증 전 Draft로 유지한다.
