# FE-01: BE-04 연결 준비

관련: [#14 담당자 답변](https://github.com/PSHUN03/Codyssey-M3-1/issues/14#issuecomment-6614467318), #22. 브랜치: `feature/FE-01-weekly-check`, 기존 Draft PR #52.

## 반영

`app/static/js/checkin-contract.js`에 주차·월·원 단위 요청 생성을 분리했다. 주차는 유효한 ISO `YYYY-Www`, 월은 `YYYY-MM`, 납입 여부는 boolean, 저축액은 원 단위 정수다. 65만 원 입력은 기존 `parseMan`을 거쳐 650,000원으로 한 번만 변환된다.

이슈 #22에 제시된 `PUT /api/checkins/{week}`·`PUT /api/savings/{month}`에 사용할 요청 객체를 만든다. 아직 HTTP 요청은 보내지 않는다. 현재 샘플 저장도 이 요청의 값 검증을 재사용하며 같은 주·월은 기존 샘플 값을 교체한다. 샘플 저장소 범위·카드·차트·보라색 CSS는 유지했다.

## 연결 시 이어서 할 일

1. BE-04 구현 PR/환경과 실제 경로·요청 본문을 최종 대조한다.
2. 저장·조회 응답 예시를 받은 뒤 응답 변환과 API 데이터 소스를 연결한다. 현재 실제 응답 스키마를 가정한 코드는 없다.
3. 기존 보유 저축 포함 여부 등 진행률 기준을 합의한 뒤 실제 진행률에 적용한다. 샘플 합계를 실데이터 진행률로 사용하지 않는다.
4. 서버 저장 성공 후 화면 갱신, 실패·인증 만료·새로고침 후 재조회까지 확인한다. 아직 실제 저장·조회 완료로 보고하지 않는다.

## 검증

- Node 요청 계약·샘플 회귀 15개 통과. ISO 연말 주차, 문자열 boolean 거부, 만 원→원, 같은 기간 덮어쓰기, 음수·소수 검증을 포함한다.
- pytest 108개, Ruff·JS 구문·diff 검사 통과.
- 실제 앱 360px·1440px에서 계약 스크립트 로드, 기존 보라색·화면 폭, 체크·코치 진입·월 기록·진행률 페이지 이동을 확인한 16개 통과. 샘플 동작 중 서버 변경 요청 및 JS 오류 0.

Codex로 요청 분리·형식 검증과 회귀 확인을 수행했다. 샘플 모드 유지, 실제 요청 미활성화 및 응답·진행률 계약 대기 상태를 검토했다.
