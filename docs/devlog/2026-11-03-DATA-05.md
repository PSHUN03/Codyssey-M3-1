# DATA-05 검색 평가 준비

평가 도구와 자체 작성 개발용 40문항을 DATA-01 #44에서 분리한 PR입니다. PM 최종 골든셋이 아니며 이슈 전체 완료로 닫지 않습니다.

| 데이터 | 변경 전 | 변경 후 |
|---|---|---|
| 기존 12문항 Hit@1 | 11/12 (91.7%) | 11/12 (91.7%) |
| 기존 12문항 Hit@3 | 12/12 | 12/12 |

변경 전은 10/31 정책 20개 확장 후 로컬 검증 기록, 변경 후는 11/03 최신 main 통합 후입니다. 이번 작업에서 검색 알고리즘을 변경하지 않았으며 성능 향상을 주장하지 않습니다. 40문항은 이름을 포함한 질문이 많아 일반 질의 품질 보장이 아닙니다. 기존 q10은 '연말정산 때 돈 돌려받는 방법'으로 정답 연금저축과 월세 세액공제가 모두 관련돼 PM 정답 기준 논의가 필요합니다.

`python eval/run_policy_eval.py`와 `python eval/run_policy_eval.py --dataset eval/golden_policy_qa.jsonl`로 재실행할 수 있습니다. JSON 결과는 eval/data05_*_results.json에 저장했습니다. 외부 LLM 비용은 발생하지 않습니다. PM 독립 검수 40문항이 준비되면 그 파일 경로를 --dataset으로 전달해 최종 평가해야 합니다.
