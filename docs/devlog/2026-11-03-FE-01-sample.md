# FE-01 샘플 체크인·진행률 구현

- 작성: @hyoryeomii
- 관련: #14, BE-04 #22
- 상태: API 연결 전 Draft

## 변경 범위

목업에서 확인한 보라색 카드·제목 배치와 순차 그래프 효과를 실제 앱에 옮겼다. 홈의 기존 계획·목표·비상금·혜택·코치 카드는 유지한다. 주간 체크·월 저축 샘플 카드를 추가하고, 기존 플랜의 계산·시뮬레이션을 덮어쓰지 않도록 `/progress` 화면을 추가했다.

FE-04 변경을 포함하지 않은 최신 main에서 별도 브랜치로 시작했다. main 또는 FE-04 브랜치에는 push하지 않는다.

## 확인할 동작

- 주간 냈어요/못 냈어요, 코치 진입, 월 기록의 덮어쓰기 및 0원.
- 만 원 입력 → 원 단위 내부값, 목표 초과 수치와 100% 상한의 시각적 진행률.
- 같은 탭의 홈·플랜·기록 이동 및 새로고침, 사용자별 샘플 격리.
- 모바일 360px·PC 1440px, 작은 화면·가로 화면 및 제목 정렬.
- 스크롤 전 대기 → 왼쪽부터 순차 상승, 동작 줄이기 설정.
- 기존 플랜 계산·진단·코치 등 회귀 검사.

## 구현 지원

Codex로 코드 작성과 자동 검사를 보조했다. 날짜·금액 단위·샘플 격리와 기존 기능 보존을 확인하며 수정했다. 샘플 검증을 실제 저축 API 또는 실기기 설치 검증으로 기록하지 않는다.

차트 선택과 API 연결 전 질문은 [ADR-0010](../adr/0010-fe01-sample-savings-svg.md)에 정리했다. BE-04 연결 및 배포·실기기 확인 후 Draft 상태를 해제한다.
