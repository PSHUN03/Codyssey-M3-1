# FE-05 / FR-19 영수증 샘플 화면

관련: #18, #26 · 상태: API 연결 전 Draft

승인된 보라색 목업을 실제 앱으로 옮겼다. 최신 main 기준의 독립 브랜치에서 작업하고 기존 FE-01·FE-04 변경은 포함하지 않는다. 플랜에 진입 링크를 추가하고, 영수증 페이지의 오른쪽 상단에 작은 ‘← 뒤로가기’를 두어 원래 플랜으로 돌아가게 했다.

사진 미리보기·유형·5MB 검사, 샘플 인식 결과의 수정·완료 표시를 구현했다. 실제 사진 인식과 서버 저장은 수행하지 않는다. 화면에는 선택한 사진과 무관한 예시 결과임을 표시하고, `?example=missing`에서는 못 읽은 금액을 직접 입력하는 상황을 확인할 수 있다.

초기 확인: Ruff, pytest 107개, Node 금액·파일·날짜·누락값 검사 10개와 JavaScript 구문 검사 통과. 실제 앱 모바일·PC 브라우저 검증은 이어서 수행하고 결과·화면 캡처를 추가한다.

Codex로 코드 작성과 검증을 보조했다. 금액의 부호·소수점이 기존 공통 숫자 필터에서 제거되지 않도록 자체 검증하고, 서버로 사진이나 재무 데이터를 보내지 않는지 검토했다. AI-02 계약·저장 API·배포·실기기 검증은 남아 있다.
