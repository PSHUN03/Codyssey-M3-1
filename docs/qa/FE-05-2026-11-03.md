## 재현한 흐름

1. `/demo` 예시 계정으로 `/home`·`/plan`·영수증 화면의 제목 위치·크기를 비교한다. 공통 제목 스타일을 유지한다.
2. 기존 플랜의 ‘영수증 기록하기’ 링크를 누른다. 새 페이지의 오른쪽 상단에 작은 ‘← 뒤로가기’가 있으며 목적지는 항상 `/plan`이다. 플랜 메뉴가 활성화된다.
3. 기본 샘플 결과에서 날짜·가맹점·금액을 고쳐 저장한다. 빈 값, 음수, 소수, 지수 표기, 잘못된 쉼표 표기는 거부한다. 키보드 Enter로도 확인할 수 있다.
4. 샘플 가맹점·20,000원·2026-11-02를 입력해 완료 결과에 같은 값이 나오는지 확인한다. 체크는 68px 배경·36px 아이콘이고 왼쪽에서 오른쪽으로 한 번 그려진다. 동작 줄이기에서는 정적으로 표시된다.
5. PDF·5MB 초과·빈 이미지·손상 이미지를 거부한다. 가상의 영수증으로 만든 PNG를 선택하면 전송 없이 미리 보이고 긴 파일명도 줄 바꿈된다.
6. ‘샘플 결과 보기’를 누르면 준비 중 안내 후 가상 결과가 표시된다. 선택한 사진과 관계없는 예시 결과임을 명시한다. 샘플 사진으로 돌아갈 때 이전 object URL을 해제한다.
7. 체크·입력·미리보기·샘플 저장 동안 서버 변경 요청이 발생하지 않는지 확인한다. 실제 금융 데이터나 사진을 저장하지 않는다.
8. `/plan/receipts?example=missing`에서 못 읽은 금액은 빈칸으로 남고 직접 입력해야 한다.
9. ‘뒤로가기’를 눌러 원래 플랜에 복귀한다. 기존 월 30만 원·24개월 적금 계산이 정상 동작한다.
