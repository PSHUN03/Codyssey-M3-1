## 확인한 사용자 흐름

1. `/demo` 예시 계정으로 홈을 열고 기존 저축·목표·비상금 카드가 유지되는지 확인한다. 주간·월간 카드에는 샘플임이 표시된다.
2. 월 금액을 입력한 상태에서 ‘못 냈어요’를 누른다. 입력 중인 금액이 유지되고 기존 `/coach`로 가는 버튼이 나타난다. ‘냈어요’를 누르면 코치 버튼이 숨겨지고 선택 상태가 바뀐다.
3. 이번 달 샘플 65만 원을 70만 원으로 수정한다. 새로고침 후에도 같은 탭에서는 유지된다. `/progress`의 합계는 325만 원, 진행률은 10.8%, 이번 달 기록은 70만 원이 된다.
4. 0만 원으로 바꾸면 합계는 255만 원이 된다. 4,000만 원이면 합계 4,255만 원·141.8%를 표시하고 시각적 진행 막대는 100%에서 멈춘다. 같은 달을 다시 입력해도 중복 합산하지 않는다.
5. 빈 값, 음수, 소수 및 입력 상한 초과를 제출하면 인라인 오류가 나타난다. 기존 공통 숫자 필터가 부호·소수점을 제거해 다른 금액으로 바꾸지 않도록 이 입력은 자체 검증한다.
6. 샘플 체크·입력 동안 서버로 변경 요청이 발생하지 않는지 확인한다. 새 예시 계정으로 바꾸면 이전 사용자의 샘플 수정이 나타나지 않는다.
7. 각 화면 크기에서 가로 넘침·SVG 수치 잘림이 없고, 홈과 기록 화면 제목의 위치·크기가 같은지 확인한다. 기록 화면에 ‘홈으로’ 버튼이 없으며 플랜 메뉴가 활성화된다.
8. 360×600 화면에서 그래프가 화면 밖에 있을 때 대기하고, 스크롤로 보이면 왼쪽부터 상승하는지 확인한다. 완료 후 리사이즈는 효과를 반복하지 않는다. 동작 줄이기 설정에서는 즉시 최종값을 보여 준다.
9. 기존 `/plan`의 계산·다시 계산 버튼과 기록 진입 링크를 확인한다. 월 30만 원·24개월을 입력하여 기존 적금 계산 결과가 나타나는지 확인한다.
