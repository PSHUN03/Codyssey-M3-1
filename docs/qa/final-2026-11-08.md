## 발견하고 고친 문제

| 문제 | 원인 | 조치 |
|---|---|---|
| 거래내역 저장(`/api/transactions/upload`, `/save`)이 배포본에서 모두 500 | BE-01 머지 중 `Transaction.created_at`이 모델에서 빠짐. 배포 DB에는 NOT NULL 열로 남아 INSERT 실패. 테스트 DB는 새로 만들어져 잡히지 않음 | #81에서 열 복구, 회귀 테스트 추가. 배포본에서 저장 4건·업로드 1건 200 확인 |
| `/progress`가 "진행률 연결 준비 중"으로만 표시 | 서버가 진행률을 주기 전 계약대로 화면이 고정 | #80에서 서버 진행률 표시 |
| 실제 영수증을 인식해도 "샘플" 문구 | 샘플 흐름 문구를 그대로 사용 | #80에서 사진일 때 "AI 인식", "확인 완료" |
| 영수증 r07의 가려진 합계를 12,000원으로 추측 | 모델이 프롬프트를 어김 | #80에서 서버가 한 번 더 거름. 배포본 r07 합계 null 확인 |
| `/spending`에서 저장·월별 요약이 "준비 중" | 화면이 저장 API와 연결되지 않음 | #80에서 저장 버튼과 월별 요약 연결 |
