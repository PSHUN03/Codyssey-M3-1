# 사용자 테스트 참여 동의서

**프로젝트**: 사다리 — 청년을 위한 개인별 자산관리 AI 코치 (코디세이 AI 네이티브 Final-Project)
**진행 팀**: ○○○ 팀 · 문의: (팀 대표 이메일)

## 테스트 안내

- **목적**: 서비스의 사용성과 유용성을 확인하고 개선하기 위함입니다. 참여자를 평가하는 것이 아닙니다.
- **내용**: 약 30분 동안 과제 수행, 1주일 자유 사용, 5분 설문, (선택) 7분 인터뷰
- **보상**: (있다면 기재)
- **참여는 자유**이며, 언제든 이유 없이 그만둘 수 있습니다.

## 수집하는 정보

| 항목 | 목적 | 보관 |
|---|---|---|
| 서비스에 입력한 재무 정보·대화 | 서비스 제공 | 탈퇴 시 즉시 삭제, 늦어도 2026-12-31 삭제 |
| 과제 수행 관찰 메모, 설문·인터뷰 응답 | 서비스 개선, 프로젝트 발표 | 익명(T-01 등)으로 처리, 2026-12-31 삭제 |

- 실제 재무 정보 대신 **가상 데이터(예시 계정)**로 참여할 수 있습니다.
- 발표 자료에는 개인을 알아볼 수 없는 통계와 익명 인용만 사용합니다.
- AI 답변 생성을 위해 입력 내용이 Anthropic(미국)의 Claude API로 전송될 수 있습니다.
