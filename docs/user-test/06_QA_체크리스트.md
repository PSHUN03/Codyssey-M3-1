# 배포 전 QA 체크리스트

> 모바일(안드로이드 크롬, iOS 사파리)과 PC 크롬에서 각각 확인합니다. 실패 항목은 `bug` 이슈로 등록합니다.

## 랜딩·계정·동의
- [ ] 랜딩 계산기에 월급·월세·고정비를 넣으면 저축 금액과 막대가 바로 바뀐다
- [ ] "부모님과 살아요"를 고르면 월세 칸이 사라지고 저축 비율이 올라간다
- [ ] 랜딩, 회원가입, 동의 화면 순서로 이동한다
- [ ] "모두 동의해요"를 누르면 모든 항목이 체크되고, 필수 하나를 빼면 진행되지 않는다
- [ ] 로그아웃 후 다시 로그인하면, 진단을 이미 했을 때 홈으로 이동한다
- [ ] "예시 계정으로 둘러보기"가 바로 홈으로 이동하고, 다른 브라우저의 예시 계정과 섞이지 않는다

## 재무 진단
- [ ] 위쪽 진행 막대와 "n / m"이 질문마다 바뀐다
- [ ] 월세를 고르면 월세 질문이, 대출이 있다고 하면 대출 질문 두 개가 추가된다
- [ ] 금액 칸 아래에 원 단위 금액(예: 2,450,000원)이 표시된다
- [ ] 월급에 "2450000"처럼 너무 큰 값을 넣으면 단위를 확인하라는 안내가 나온다
- [ ] 뒤로 가기 버튼으로 이전 질문에 돌아가면 이전 답이 채워져 있다
- [ ] 목표 문장("1년 반 안에 500만 원")이 금액 500만 원, 기간 18개월로 정리된다
- [ ] 마지막 확인 화면에서 "고치기"로 항목을 바꾸면 다시 확인 화면으로 돌아온다
- [ ] 완료 후 플랜 화면으로 이동한다

## 플랜·혜택
- [ ] 배분 금액의 합이 월 실수령액과 같다
- [ ] 실제 AI 모드에서 플랜 설명에 'AI 설명' 표시가 있다
- [ ] 적금 계산이 일반 적금과 청년미래적금 모두 된다
- [ ] 혜택 목록이 상태별로 묶이고, 상세에 출처 링크와 기준일이 있으며 링크가 열린다

## AI 코치
- [ ] 답변이 조금씩 흘러나온다(스트리밍)
- [ ] 정책 질문 답변에 "출처 n개"가 붙는다
- [ ] "삼성전자 사도 돼?"에 투자 권유를 하지 않는다
- [ ] 답변 아래 좋아요·아쉬워요 버튼이 눌리고, 아쉬워요는 의견 입력 창이 뜬 뒤 안내 토스트가 뜬다
- [ ] "배달 주 2회만 할게"가 내 정보의 '코치가 기억하는 내용'에 나타나고, 지우면 사라진다
- [ ] 모바일에서 입력창이 하단 탭과 겹치지 않는다

## 내 정보·기타
- [ ] 재무 정보를 만 원 단위로 고쳐 저장하면 플랜이 다시 계산된다
- [ ] 탈퇴 확인 창에서 취소하면 아무 일도 없고, 탈퇴하면 같은 계정으로 로그인할 수 없다
- [ ] 없는 주소에서 404 화면이 나온다
- [ ] 홈 화면에 추가(PWA)가 되고, 설치된 앱에서 레이아웃이 깨지지 않는다
- [ ] 데스크톱(1440px)에서 상단 메뉴가, 모바일(375px)에서 하단 탭이 보인다
