# 사용자 테스트 진행 가이드

> 담당: PM (PM-03) · 기간: 1차 10/24~11/1, 2차 11/4~11/6 · 목표 인원 10명(최소 5명)

## 1. 목표

1. 사회초년생이 **도움 없이** 진단 → 플랜 → 혜택 확인 → 코치 상담을 할 수 있는가 (사용성)
2. 사다리가 **새로 알게 된 혜택**과 **실천할 행동**을 주는가 (가치)
3. 1주일 동안 **다시 찾아오는가** (유지)

## 2. 테스터 모집

- 조건: 만 19~34세, 월 소득이 있는 청년 (정규직·계약직·프리랜서·아르바이트)
- 모집 경로: 코디세이 동료, 지인, 대학·지역 커뮤니티
- 실제 재무 정보 입력이 부담되면 **예시 계정(가상 인물 '지우')**로 참여해도 된다고 안내

**모집 문구 예시**
> 첫 월급 관리를 도와주는 AI 코치 '사다리'를 만들고 있어요. 30분 체험 + 1주일 자유 사용 + 5분 설문에 참여해주실 만 19~34세 직장인·사회초년생을 찾습니다. 실제 정보 대신 가상 데이터로도 참여할 수 있고, 테스트가 끝나면 데이터는 삭제돼요.

## 3. 진행 순서 (1인 30분, 대면 또는 화면 공유)

| 단계 | 시간 | 내용 |
|---|---|---|
| 안내·동의 | 3분 | 목적 설명, [참여 동의서](02_참여동의서.md) 서명, "서비스를 평가하는 거지 당신을 평가하는 게 아니에요" |
| 과제 수행 | 15분 | 아래 과제를 소리 내어 생각하며(think-aloud) 수행. 진행자는 **도와주지 않고** 관찰·기록 |
| 설문 | 5분 | [설문지](03_설문지.md) |
| 짧은 인터뷰 | 7분 | [인터뷰 가이드](04_인터뷰가이드.md) (5명 선정) |

## 4. 과제 시나리오

| # | 과제 | 성공 기준 | 기록할 것 |
|---|---|---|---|
| T1 | 가입하고 재무 진단을 끝내세요 | 5분 이내 완료 | 소요 시간, 막힌 질문 |
| T2 | 내 월급이 어떻게 나뉘었는지 확인하고, 이해한 대로 설명해보세요 | 배분 이유를 말할 수 있음 | 헷갈린 용어 |
| T3 | 받을 수 있는 혜택 하나를 골라 신청 방법을 찾아보세요 | 출처·신청 방법 확인 | 새로 알게 된 혜택 수 |
| T4 | 코치에게 평소 궁금했던 돈 질문 3개를 해보세요 | 답변 만족도 4/5 이상 | 질문 원문, 만족도 |
| T5 | 코치에게 이번 주 지킬 약속 하나를 말해보세요 | 설정의 '기억'에 저장됨 | 저장 여부 |
| T6 | 1주일 동안 자유롭게 사용하세요 | 3회 이상 재방문 | 방문 횟수(로그) |

## 6. 피드백 처리

1. 관찰 메모·설문·인터뷰에서 의견을 뽑아 `user-feedback` 이슈로 등록한다 (템플릿 사용).
2. 주간 회고에서 영향도 × 빈도로 우선순위를 정한다.
3. 반영하면 이슈에 **Before/After** (스크린샷·지표)를 남기고 PR과 연결한다.
4. 결과는 [결과 보고서](05_결과보고서_양식.md)와 README '사용자 테스트 결과'에 정리한다.

## 7. 윤리

- 테스터의 실제 재무 정보는 팀원끼리도 공유하지 않는다 (지표와 익명 의견만 공유).
- 테스트가 끝나면 원하는 테스터의 계정을 삭제한다 (설정 → 탈퇴).
- 녹화·녹음은 별도 동의가 있을 때만 한다.
