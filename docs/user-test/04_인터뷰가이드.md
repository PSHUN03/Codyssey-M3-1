# 인터뷰 가이드 (7분, 5명)

> 원칙: 답을 유도하지 말고, "왜 그렇게 생각하셨어요?"로 한 번 더 파고든다. 해결책보다 **경험**을 묻는다.

## 1. 평소 돈 관리 (2분)
- 첫 월급(또는 최근 월급)을 받고 가장 먼저 한 일은 무엇이었나요?
- 돈 관리에서 가장 막막했던 순간을 이야기해줄 수 있나요?
- 청년 정책 정보는 주로 어디서 얻나요? 그때 어떤 점이 어려웠나요?

## 2. 사다리 경험 (3분)
- 방금 쓰면서 "오, 이건 좋다" 싶었던 순간이 있었나요?
- 멈칫하거나 헷갈렸던 순간은요? 그때 무엇을 기대했나요?
- 코치 답변 중 믿기 어렵거나 너무 일반적이라고 느낀 것이 있었나요?
- 월급 배분 비율(저축 45% 등)이 내 상황에 맞다고 느꼈나요? 아니라면 어떻게 달라야 할까요?

## 3. 지속 사용 (2분)
- 테스트 기간 동안 다시 들어오게 만든 것(또는 안 들어오게 만든 것)은 무엇이었나요?
- 매주 오는 체크인 리포트가 있다면 어떤 내용이면 열어볼 것 같나요?
- 한 가지만 바꿀 수 있다면 무엇을 바꾸겠어요?
