# 사용자 테스트 설문지

> 구글 폼은 [08_구글폼_생성.gs](08_구글폼_생성.gs)로 만듭니다. 문항 제목이 코드(`A1.`, `B1.` 등)로 시작해야 [집계 스크립트](../../scripts/user_test_summary.py)가 읽습니다.
> 이름, 연락처, 이메일은 받지 않습니다. 응답은 익명으로 저장합니다.

각 질문이 무엇을 확인하려는 것인지 함께 적었습니다. 사다리의 흐름(진단 → 월급 배분 → 청년 혜택 → AI 코치 → 실천)을 따라 묻습니다.

## 1. 응답 활용 동의 (필수)

| 코드 | 문항 | 형식 |
|---|---|---|
| P1 | 이 설문의 응답은 이름이나 연락처 없이 저장되며, 사다리 개선과 코디세이 프로젝트 발표에 통계와 익명 인용으로만 쓰입니다. 응답은 2026년 12월 31일에 삭제합니다. 동의하십니까? | 체크박스 |

## 2. 응답자 정보

사다리의 주 대상(첫 월급을 받은 지 0~3년 된 사회초년생)과 응답자가 얼마나 가까운지 확인합니다.

| 코드 | 문항 | 선택지 | 확인하려는 것 |
|---|---|---|---|
| A1 | 나이대 | 10대 / 20대 / 30대 / 40대 / 50대 / 60대 이상 | 연령 분포 |
| A2 | 지금 하고 있는 일 | 학생 / 취업 준비 중 / 직장인(정규직) / 직장인(계약직·인턴) / 프리랜서·자영업 / 아르바이트 / 기타 | 소득 형태 |
| A3 | 첫 월급(일해서 처음 번 소득)을 받은 지 얼마나 됐나요? | 아직 받은 적 없음 / 1년 미만 / 1~3년 / 3~5년 / 5년 이상 | 사회초년생 여부 |
| A4 | 지금 돈 관리는 어떻게 하고 있나요? (모두 선택) | 가계부 앱 / 은행·카드 앱에서 내역만 확인 / 엑셀이나 메모 / 따로 관리하지 않음 / 기타 | 기존 습관 |
| A5 | 청년미래적금, 청년월세 지원 같은 청년 금융 혜택을 신청해 본 적이 있나요? | 신청해 봤다 / 알고는 있지만 신청하지 않았다 / 잘 모른다 | 혜택 인지 수준 |
| A6 | 사다리를 어떻게 써 봤나요? | 직접 가입해 내 실제 정보로 / 직접 가입했지만 지어낸 정보로 / 예시 계정(가상 인물 지우)으로 둘러봄 | 응답의 맥락 |

## 3. 사용한 기능

| 코드 | 문항 | 선택지 |
|---|---|---|
| U1 | 써 본 기능을 모두 골라 주세요. | 재무 진단(질문 카드) / 월급 배분 플랜 / 청년 혜택 찾기와 자격 확인 / AI 코치 상담 / 코치가 기억하는 내용(설정) / 로그인 없이 쓰는 월급 계산기 |
| U2 | 재무 진단(질문 카드)을 끝내는 데 걸린 시간 | 3분 이내 / 3~5분 / 5~10분 / 10분 넘게 / 끝내지 못함 / 진단을 하지 않음(예시 계정 등) |
| U3 | 가장 도움이 된 기능 하나를 골라 주세요. | U1 선택지 + 도움이 된 기능이 없음 |

U2는 요구사항 FR-03 인수 기준(테스터 80% 이상이 5분 안에 진단 완료)을 확인합니다.

## 4. 사용 편의성 (SUS 10문항, 1=전혀 아니다 ~ 5=매우 그렇다, 필수)

표준 사용성 척도(SUS)를 사다리에 맞는 쉬운 말로 옮겼습니다. 홀수는 긍정, 짝수는 부정 문장이라는 원래 구조는 그대로입니다.

| 코드 | 문항 |
|---|---|
| B1 | 사다리를 자주 쓰고 싶다. |
| B2 | 사다리는 필요 이상으로 복잡하다. |
| B3 | 사다리는 쓰기 쉬웠다. |
| B4 | 사다리를 쓰려면 다른 사람의 도움이 필요할 것 같다. |
| B5 | 진단, 플랜, 혜택, 코치 기능이 자연스럽게 이어졌다. |
| B6 | 화면마다 쓰는 방식이 달라 헷갈리는 부분이 많았다. |
| B7 | 대부분의 사람이 사다리 사용법을 금방 익힐 것 같다. |
| B8 | 사다리는 쓰기 번거로웠다. |
| B9 | 사다리를 쓰는 동안 다음에 무엇을 하면 되는지 알고 썼다. |
| B10 | 사다리를 쓰기 전에 따로 익혀야 할 것이 많았다. |

> **SUS 점수 계산**: 홀수 문항은 (점수 − 1), 짝수 문항은 (5 − 점수)를 더한 뒤 × 2.5 → 0~100점. 68점이 평균, 목표는 70점 이상(NFR-09).

## 5. 기능별 평가 (1=전혀 아니다 ~ 5=매우 그렇다, 써 보지 않은 기능은 비워 둠)

| 코드 | 문항 | 확인하려는 것 |
|---|---|---|
| C1 | 재무 진단 질문이 무엇을 묻는지 이해하기 쉬웠다. | 진단 질문의 명확성 (FR-03) |
| C2 | 월급 배분 플랜에서 각 금액이 왜 그렇게 나뉘었는지 이해할 수 있었다. | 배분 근거 설명 (FR-05) |
| C3 | 월급 배분 플랜이 내 실제 생활(고정비, 생활비, 저축)에 맞았다. | 배분의 현실성 |
| C4 | 청년 혜택마다 내가 받을 수 있는지와 그 이유가 분명하게 나왔다. | 자격 판정 근거 (FR-07, 08) |
| C5 | AI 코치의 답변이 내 소득과 지출 상황을 반영했다. | 개인화 (FR-09, 10) |
| C6 | AI 코치가 알려 준 금액과 정보를 믿을 수 있었다. | 신뢰, 수치 정확성 (FR-11) |
| C7 | AI가 만든 답변이라는 표시와 한계 안내를 알아볼 수 있었다. | AI 생성 표시 (과제 윤리 요건, NFR-11) |
| C8 | 사다리에 내 재무 정보를 입력하는 것이 부담스럽지 않았다. | 개인정보 입력 부담 |
| C9 | 사다리를 쓰고 나서 이번 달에 해 볼 구체적인 행동(저축액 조정, 혜택 신청 등)이 생겼다. | 실천으로 이어지는지 |

## 7. 전체 평가와 의견

| 코드 | 문항 | 형식 |
|---|---|---|
| E1 | 다음 월급을 받았을 때도 사다리로 배분을 확인하거나 코치에게 물어볼 생각이 있나요? | 예 / 아마도 / 아니요 |
| E2 | 친구나 동료에게 사다리를 추천할 가능성은 얼마나 되나요? | 0~10 (NPS) |
| E3 | 가장 좋았던 점은 무엇인가요? (어느 기능에서 어떤 점이 좋았는지) | 장문형, 선택 |
| E4 | 헷갈리거나 불편했던 점은 무엇인가요? (어느 화면에서 무엇이 그랬는지) | 장문형, 선택 |
| E5 | 무엇이 바뀌거나 추가되면 사다리를 계속 쓰시겠어요? | 장문형, 선택 |

> **NPS 계산**: 9~10점 비율 − 0~6점 비율. 범위는 −100~+100.
