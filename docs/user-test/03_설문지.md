## A. 기본 정보
1. 테스터 ID: T-__
2. 나이대: 19~24 / 25~29 / 30~34
3. 일하는 형태: 정규직 / 계약직 / 프리랜서 / 아르바이트 / 기타
4. 평소 가계부나 자산관리 앱을 쓰나요? 매일 / 가끔 / 거의 안 씀 / 써본 적 없음

## B. 사용성 (SUS, 1=전혀 아니다 ~ 5=매우 그렇다)
1. 이 서비스를 자주 사용하고 싶다.
2. 이 서비스는 불필요하게 복잡하다.
3. 이 서비스는 사용하기 쉬웠다.
4. 이 서비스를 쓰려면 기술적인 도움이 필요할 것 같다.
5. 이 서비스의 여러 기능이 잘 어우러져 있다.
6. 이 서비스에는 일관성이 없는 부분이 너무 많다.
7. 대부분의 사람들이 이 서비스를 금방 배울 것 같다.
8. 이 서비스는 사용하기 번거롭다.
9. 이 서비스를 사용하면서 자신감이 있었다.
10. 이 서비스를 쓰기 전에 배워야 할 것이 많았다.

> **SUS 점수 계산**: 홀수 문항은 (점수 − 1), 짝수 문항은 (5 − 점수)를 더한 뒤 × 2.5 → 0~100점. 68점이 평균, 목표는 70점 이상.

1. 월급 배분 플랜의 이유를 이해할 수 있었다.
1-1. 진단 결과로 나온 내 유형(적자 / 저축 여력 부족 / 저축 여력 있음 / 저축 유지 어려움)이 내 상황과 맞았다.
2. 코치의 답변이 내 상황에 맞았다.
3. 코치의 답변을 믿을 수 있었다.
4. 이번 주에 실천할 행동이 분명해졌다.
5. 주변 청년에게 추천하고 싶다. (0~10점, NPS)
