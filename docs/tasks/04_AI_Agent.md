## [AI-06] Agent 검증 단계 보강
라벨: AI, 안전, 멘토피드백, Must
마감: 10/29

**목표**: "계산은 코드, 설명은 AI" 원칙이 예외 상황에서도 지켜지게 한다. 지금은 답변 속 금액을 도구 결과와 대조해 표시만 한다. 멘토 피드백: 도구 실행 실패, 필수 데이터 누락, 계산 결과와 답변 불일치를 어떻게 처리할지까지 정해야 한다.

**완료 기준**
- [ ] 도구 실행이 실패하면 추측해서 답하지 않고, 지금 계산할 수 없다는 안내와 다시 시도할 방법을 보여준다
- [ ] 필수 데이터(실수령액 등)가 비어 있으면 계산 대신 그 값을 먼저 묻는다
- [ ] 근거 없는 금액이 나온 답변은 표시에 그치지 않고 계산 결과대로의 문장으로 바꾸거나 다시 생성한다 (`app/services/agent/guardrails.py`, `coach.py`)
- [ ] 세 경우 각각 모의 모드 테스트 추가
- [ ] 질문에 따라 Agent가 어떤 도구를 고르는지 그림 한 장으로 정리해 `docs/04_AI활용설계.md`에 추가

## [AI-07] 장기 메모리 저장 항목과 보관 기간
라벨: AI, 개인정보, 멘토피드백, Should
마감: 10/30

**목표**: 소득·부채·거주 형태 같은 재무 정보는 메모리가 아니라 DB에만 둔다는 원칙을 코드와 화면으로 보여준다. 멘토 피드백: 저장 항목 목록, 사용자가 보고 지우는 기능, 보관 기간을 설계에 넣어야 한다. 지자체·대학 공급 계획에도 필요하다.

**완료 기준**
- [ ] 메모리에 저장할 수 있는 항목을 코칭 선호·약속·맥락으로 정하고, 금액·부채 같은 재무 수치가 들어간 내용은 저장하지 않도록 거른다 (`app/services/agent/memory.py`)
- [ ] 보관 기간을 정하고 (예: 마지막 사용 후 6개월) 지난 메모리를 지우는 방법 구현
- [ ] 설정 화면 "AI가 기억하는 나"와 개인정보처리방침(`app/templates/privacy.html`)에 저장 항목과 보관 기간 표시
- [ ] 테스트 추가
