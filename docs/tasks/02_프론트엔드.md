## [FE-01] [FR-16] 주간 체크와 목표 진행률 대시보드
라벨: 프론트엔드, FR-16, 멘토피드백, Should
마감: 10/28

**목표**: 계좌 연동 없이도 매주 납입 여부를 알 수 있게 하고, 목표 진행률과 월별 추이를 차트로 본다. 계획을 '유지'하게 만드는 핵심 화면이다. 멘토 피드백: 매주 거래내역을 다시 올리게 하면 이탈하기 쉬우니, 한 번 탭으로 끝나는 체크가 필요하다.

**완료 기준**
- [ ] 홈 화면에 "이번 주 냈나요?" 한 번 탭 체크 (냈어요 / 못 냈어요). 못 냈으면 코치 상담으로 이어지는 버튼 (BE-04 API 사용)
- [ ] 홈 화면에 "이번 달 얼마 모았나요?" 체크인 카드 (BE-04 API 사용)
- [ ] `/plan` 또는 새 `/progress` 화면에 목표 진행률 막대와 월별 저축 추이 차트
- [ ] 차트는 외부 라이브러리 없이 SVG로 그리거나 Chart.js CDN 사용 (결정을 ADR로 기록)
- [ ] 모바일(360px)과 데스크톱(1440px)에서 확인

**구현 가이드**: `app/templates/home.html`, `app/static/js/app.js`의 `initPlan` 참고. 색, 서체, 카드 모양은 `app/static/css/app.css`의 토큰과 [ADR-0008](../adr/0008-design-system.md)을 따르고, 차트에는 강조색 라임 하나만 쓴다. API 계약은 BE-04 담당과 먼저 맞춘다.

## [FE-02] [FR-14] 소비 분석 화면
라벨: 프론트엔드, FR-14, Should
마감: 10/30

**목표**: 거래내역을 올리면 카테고리별 지출, 고정비·변동비, 새는 돈(구독 등)을 한눈에 본다.

**완료 기준**
- [ ] `/spending` 화면: 파일 업로드(엑셀·CSV), 업로드 진행 상태, 오류 안내
- [ ] 카테고리별 지출 도넛(또는 막대) 차트와 상위 지출 목록
- [ ] 분류가 틀린 거래를 사용자가 바꿀 수 있는 선택 상자
- [ ] 하단 탭(모바일)과 상단 메뉴(데스크톱) 또는 플랜 화면에서 진입

**구현 가이드**: API는 BE-01(업로드·요약 API)과 DATA-06(엑셀 변환·분류)이 만든다 (`POST /api/transactions/upload`, `GET /api/transactions/summary`).
