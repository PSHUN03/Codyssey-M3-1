# ADR-0002: Claude API를 쓰고, 키가 없으면 모의 AI 모드로 동작한다

- 날짜: 2026-09-30
- 상태: 채택

## 배경
개발 시작 시점에 LLM API 키가 없었다. 테스트·CI·팀원 로컬 개발에서 매번 API 비용이 들거나 키를 공유하는 것은 위험하다.

## 결정
1. **공급자**: Claude API. 코치 Agent는 `claude-opus-5-5`, 추출·분류·요약 같은 경량 작업은 `claude-haiku-4-5`를 기본값으로 쓴다. 두 값 모두 환경변수(`COACH_MODEL`, `FAST_MODEL`)로 바꿀 수 있다.
2. **모의 모드**: `ANTHROPIC_API_KEY`가 없으면 `LLM_PROVIDER=mock`으로 동작한다. 모의 코치는 규칙으로 의도를 판단하지만 **실제 코치와 같은 도구를 호출**하므로 숫자와 데이터 흐름은 같다.
3. **거절 폴백**: Opus 5.5 사용 시 서버 측 거절 폴백(`fallbacks: "default"`)을 켜 두어, 안전 분류기가 오탐으로 응답을 멈추면 다른 모델이 이어받게 한다. `REFUSAL_FALLBACK=false`로 끌 수 있다.

## 결과
- 테스트 75개가 API 키 없이 돌아가고 CI 비용이 0원이다.
- 코치 화면 안내 문구에 모의 모드라고 표시되어 실제 AI와 구분된다. (2026-10-01 화면 개편 때 상단 배지에서 옮김, ADR-0008)
- 모의 모드 응답은 템플릿이라 자연스러움이 떨어진다. 사용자 테스트 전에는 반드시 실제 키를 연결한다.
- 비용과 품질은 평가셋(`eval/run_eval.py --live`)으로 비교한 뒤, 필요하면 코치 모델을 `claude-sonnet-5-5`로 바꾸는 것을 팀이 결정한다.
