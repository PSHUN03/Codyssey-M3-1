# ADR-0011: FE-05 영수증 화면의 샘플 어댑터

- 날짜: 2026-11-03
- 상태: 제안 (API 계약 확인 전 Draft)
- 작성: @hyoryeomii
- 관련: #18 (FR-19), #26 (AI-02)

## 결정

기존 `/plan`에 진입 링크를 추가하고 `/plan/receipts`에서 영수증 사진과 확인 폼을 보여 준다. 기존 플랜 계산·진단·시뮬레이션은 보존한다. 공통 레이아웃과 제목의 색·크기·위치를 그대로 재사용하고, 오른쪽 상단의 작은 ‘뒤로가기’ 링크는 항상 `/plan`으로 이동한다. 경로가 `/plan` 아래라 기존 플랜 메뉴가 활성화된다.

AI-02 요청·응답 및 확인 후 저장 API가 합의되기 전에는 **명시적인 샘플 모드**만 사용한다. 선택한 사진은 브라우저의 object URL로만 미리 보고, 교체·페이지 종료 시 해제한다. 사진·입력값·샘플 기록을 서버나 브라우저 저장소로 전송·저장하지 않는다. 샘플 결과는 선택한 사진과 관계없는 가상 데이터임을 표시한다.

JPEG/PNG 및 5×1024×1024바이트 한도는 미리보기 전에 검사하고, 손상된 이미지도 거부한다. 실제 업로드 API를 연결하면 서버도 파일 유형·용량을 검증해야 한다.

샘플 내부 데이터는 ISO 날짜, 가맹점 문자열, 정수 원 단위 금액을 사용한다. 읽지 못한 금액의 샘플은 `null`로 두고 빈 입력칸과 확인 안내를 보여 준다. 사용자가 날짜·가맹점·금액을 확인·수정해야 샘플 완료 화면으로 진행한다. 이 형식은 확정된 AI-02 서버 계약이 아니다.

완료 체크는 왼쪽 끝에서 꺾이는 부분을 거쳐 오른쪽 위로 한 번 그려진다. 동작 줄이기 설정에서는 즉시 정적인 완료 표시를 보여 준다.

## 연결 전 확인할 사항

- `POST /api/receipts/scan`의 multipart 필드명, 날짜·가맹점·금액 응답 필드와 금액 단위.
- 못 읽은 값·서버 오류·인증 만료의 응답 형식.
- 사용자 확인 이후 지출을 저장할 API와 중복 저장 방지 방식.
- 실제 iOS Safari·Android Chrome의 촬영·파일 선택, 배포 환경 확인.

관련 형식 확인 요청은 #18 댓글에 올라와 있다. 이 Draft를 FR-19 전체 완료 또는 실제 AI 인식·지출 저장 완료로 처리하지 않는다.
