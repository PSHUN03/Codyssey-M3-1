# ADR-0009 (제안): 데이터 연동과 주간 발송의 경계

상태: 팀 검토 대기. 팀 합의나 운영 배포를 대신하지 않습니다.

- 정책 검색은 기존 BM25를 유지합니다. 개발용 40문항에서 목표보다 높지만 독립 PM 평가가 필요하며, 임베딩·동의어 개선을 임의로 추가하지 않습니다.
- 개인 연봉은 가구의 소득인정액이 아닙니다. 가구 규모를 모르면 해당 조건을 '확인 필요'로 둡니다.
- 외부 API 정책은 검수 시드와 다른 JSON에 저장합니다. 부분 수집/인증 실패 시 기존 자료를 삭제하지 않습니다. 저장 후 캐시와 검색 인덱스를 무효화합니다.
- 현재 구현은 단일 앱 프로세스 및 영속 디스크가 전제입니다. PostgreSQL 중심 다중 인스턴스 전환은 백엔드 담당과 결정합니다.
- 거래 파일은 표준 csv와 openpyxl로 메모리에서 처리하고 업로드 원본을 저장하지 않습니다. 금액은 정수로 검증하고 애매한 입출금 방향을 추측하지 않습니다.
- 주간 리포트는 현재 저장된 사실만 사용합니다. 납입 기록과 AI 요약은 해당 API/모델 연결 이후 확장합니다.
- 중복 이메일을 피하려 발송 전에 DB에서 선점하며, 발송 결과가 불명확하면 수동 확인합니다. 정확히 한 번 발송 보장은 제공하지 않습니다.
- n8n 호스팅은 팀 공용 인스턴스를 우선 제안하되 최종 결정은 팀장·백엔드와 합의합니다.
