# ADR-0010: FE-01 샘플 저축 기록과 SVG 차트

- 날짜: 2026-11-03
- 상태: 제안 (Draft PR에서 검토)
- 작성: @hyoryeomii · 검토 예정: @1yuxnp
- 관련 이슈: #14 (FR-16), 선행 API: #22 (BE-04)

## 2026-11-04 후속 결정: 저장·기록 조회 먼저 연결

- 기본 `/home`, `/progress`는 실제 API 모드다. 샘플은 `?example=sample`로 명시적으로 선택하고 두 화면 사이에서도 모드를 유지한다. 실데이터 오류에 샘플을 대신 표시하지 않는다.
- PR #62의 현재 구현에 맞춰 주간 저장 `PUT /api/savings/weekly-check` (`week`, `paid`), 월 저축 저장 `POST /api/savings/monthly` (`month`, 정수 원 `amount`), `GET /api/checkins`, `GET /api/savings`를 연결한다. 최종 경로 합의는 대기이며 계약 모듈 한곳에서 관리한다. 주간 조회의 임시 `deposited`는 `paid`로 변환하고 `false`를 보존한다.
- 실제 금액은 현재 서버 상한인 1,000만 원까지다. 만 원 단위를 유지하고 소수점 4자리까지 정수 원으로 변환한다. 샘플 입력·저장은 기존 검증 범위를 별도로 유지한다.
- 기록 없는 달을 0원으로 채우지 않는다. 최근 12개월에 실제 기록한 달만 표시한다. 서버의 최근 8주·12개월 범위 보완은 별도 리뷰 항목이다.
- `GET /api/savings`에 누적 진행률이 없으므로 실제 목표명·목표액과 ‘진행률 연결 준비 중’을 표시한다. 월별 합계로 누적 금액을 대신 계산하거나 저장 응답의 진행률만 일시적으로 표시하지 않는다.
- 실패한 저장은 재조회로 확인한다. 중복 요청을 막고 재조회가 입력 중인 금액을 덮어쓰지 않는다. 실제 기록은 브라우저 저장소에 캐시하지 않는다.
- BE-04 PR #62는 미병합이다. 고정 SHA와 FE-01을 별도 임시 실행본으로 조합해 검증하며 main·다른 FE 브랜치를 병합하지 않는다. PR #52는 Draft로 유지한다.

아래는 초기 샘플 단계의 결정이다. 현재 범위는 [저장·조회 연결 기록](../devlog/2026-11-04-fe01-live-api.md)을 따른다.

## 배경

BE-04의 실제 저축 기록 API 연결 전에도 홈 체크인과 목표 진행률의 동작·반응형 UI를 확인할 수 있어야 한다. 기존 플랜 계산·시뮬레이션과 재무 프로필은 보존한다.

## 결정

- 기존 보라색 토큰·카드를 재사용한다. 홈에 주간 체크와 월 저축 샘플 카드를 추가하고 `/progress`에 진행률·최근 기록·월별 차트를 제공한다. 기존 `/plan`은 보존하고 기록 화면으로 가는 링크만 추가한다.
- 차트는 외부 라이브러리 없는 SVG로 그린다. 6개 막대와 수치에 충분하고, CDN 의존성 없이 좁은 화면·스크린 리더·동작 줄이기를 처리할 수 있다.
- 그래프가 보일 때 왼쪽부터 순차 상승한다. `prefers-reduced-motion: reduce`에서는 즉시 최종값을 보여 준다. 리사이즈만으로 효과를 재시작하지 않는다.
- 현재 어댑터는 **샘플 모드 전용**이다. 가상의 목표·6개월 기록을 사용하며 실제 프로필 금액, DB, 계좌 및 BE-04 API를 읽거나 쓰지 않는다. 실제 API 오류를 샘플 데이터로 숨기는 자동 fallback도 추가하지 않는다.
- 샘플 수정은 `sessionStorage`에 사용자·월별로 분리한다. 같은 탭에서 홈과 기록 화면을 이동하거나 새로고침해도 유지되며, 서버에는 저장하지 않는다. 저장소가 차단되면 메모리에서 동작하고 새로고침 시 초기화될 수 있음을 표시한다.
- 화면 입력 단위는 만 원, 내부 샘플 금액은 정수 원이다. 같은 달을 수정하면 기존 금액을 덮어쓰며 주간 여부만 바꿔서는 금액을 더하지 않는다.

## BE-04 연결 전 합의할 사항

이 문서의 인터페이스는 확정된 서버 계약이 아니다. 아래를 @1yuxnp와 확인한 뒤 샘플 어댑터를 실제 API 어댑터로 교체한다.

- `PUT /api/checkins/{week}`, `GET /api/checkins`: ISO 주차, `paid` 요청 필드, 조회 응답·오류 형식.
- `PUT /api/savings/{month}`, `GET /api/savings`: 정수 원 단위, 월별 덮어쓰기, 최근 12개월 응답, 메모 및 입력 상한.
- 목표 진행률에 초기 보유 저축·비상금을 포함하는지, 목표와 기록을 어떻게 연결하는지. 현재 샘플 진행률은 가상 월별 기록 합계 / 가상 목표이다.
- 저장 실패·인증 만료·빈 기록 안내, 코치 도구 `get_my_finances`와의 연결.

## 남은 검증

실제 API 저장·재조회, 배포 환경 및 iOS Safari·Android Chrome 실기기 검증은 완료되지 않았다. 이 단계에서 #14를 완료 처리하지 않는다.
