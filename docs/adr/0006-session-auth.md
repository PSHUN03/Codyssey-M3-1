# ADR-0006: 인증은 이메일·비밀번호 + 서명된 세션 쿠키로 구현한다

- 날짜: 2026-09-30
- 상태: 채택 (기획 초안의 Supabase Auth를 대체)

## 배경
Supabase Auth를 쓰면 외부 서비스 계정과 키 관리가 추가된다. 단일 서비스 구조(ADR-0001)에서는 서버 세션이 가장 단순하다.

## 결정
- 비밀번호는 표준 라이브러리 `hashlib.scrypt`로 해시한다 (추가 의존성 없음).
- 로그인 상태는 Starlette `SessionMiddleware`의 서명된 쿠키(`HttpOnly`, `SameSite=Lax`, 운영 환경 `Secure`)로 유지한다.
- 필수 동의 → 재무 진단 순서를 의존성(`app/deps.py`)으로 강제한다.
- 데모 계정은 방문자마다 따로 만들어 서로의 대화가 섞이지 않게 한다.

## 결과
- 외부 인증 서비스 없이 동작한다.
- 소셜 로그인, 로그인 시도 제한(무차별 대입 방지), 오래된 데모 계정 정리는 후속 과제로 남긴다 (BE 이슈).
