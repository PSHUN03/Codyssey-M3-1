# ADR-0004: Render 무료 플랜에 배포하고, DB는 SQLite에서 PostgreSQL로 전환한다

- 날짜: 2026-09-30
- 상태: 채택

## 배경
팀 결정으로 배포 비용은 무료 플랜만 쓴다. Render 무료 웹 서비스는 15분간 요청이 없으면 잠들고(첫 접속 30초~1분 지연), 재시작하면 로컬 파일이 사라진다. Render 무료 PostgreSQL은 생성 30일 뒤 만료된다.

## 결정
- 코드는 `DATABASE_URL` 하나로 SQLite와 PostgreSQL을 모두 지원한다 (SQLAlchemy).
- **MVP 기간(~10/20)**: SQLite로 배포한다. 재시작 시 데이터가 초기화되지만 데모·내부 테스트에는 충분하다.
- **사용자 테스트 전(10/20 전후)**: Render 무료 PostgreSQL을 만들어 연결한다. 만료가 11/19 이후가 되도록 **늦게 만드는 것**이 핵심이다 (발표 11/12~13).
- **대안**: Supabase 무료 PostgreSQL(만료 없음, 1주 미사용 시 일시정지)을 쓸 수 있다. 연결 문자열만 바꾸면 된다.
- **콜드 스타트 대응**: 시연 10분 전에 접속해 서버를 깨우고, 백업 시연 영상을 준비한다.

## 결과
- 비용 0원으로 테스트와 발표를 진행할 수 있다.
- DB 생성 날짜를 놓치면 발표 직전에 데이터가 사라질 수 있으므로 백엔드 담당 이슈(BE-02)에 날짜를 명시했다.
