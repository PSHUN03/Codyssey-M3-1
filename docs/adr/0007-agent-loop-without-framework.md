# ADR-0007: Agent는 프레임워크 없이 SDK의 도구 호출 루프로 만든다

- 날짜: 2026-09-30
- 상태: 채택 (기획 초안의 LangGraph를 대체)

## 배경
코치의 흐름은 "질문 → 필요한 도구 호출(0~여러 번) → 답변"의 단일 루프다. 분기가 복잡한 다중 에이전트 구조가 아니다.

## 결정
- Anthropic Python SDK의 스트리밍 API로 도구 호출 루프를 직접 작성한다 (`app/services/agent/coach.py`, 최대 6턴).
- 도구 입력은 모델이 만든 값이므로 `run_tool`에서 타입·범위를 검증한 뒤 실행하고, 오류는 `is_error`로 모델에게 돌려준다.
- 고정 시스템 프롬프트와 도구 정의는 프롬프트 캐싱 대상으로 두고, 날짜·기억처럼 바뀌는 정보는 별도 블록에 넣는다.

## 결과
- 루프가 60줄 안팎이라 팀원 누구나 읽고 설명할 수 있다 (평가 항목: "알고리즘 원리를 팀 내에서 이해").
- 여러 에이전트가 협업하는 구조가 필요해지면 LangGraph 도입을 다시 검토한다.
