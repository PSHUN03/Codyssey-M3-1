## 기획안 파일 다시 만들기

`01_기획안.md`를 고친 뒤 아래 명령을 실행하면 PDF, 한글(HWPX), 워드(DOCX)가 모두 다시 만들어집니다. PDF는 Python과 Edge(또는 Chrome)만, DOCX는 `python-docx`가 필요합니다.

```bash
python docs/tools/build_plan_pdf.py
python docs/tools/build_plan_docs.py
```

- 양식 칸(도메인·팀명·프로젝트명·팀장명)은 파일 맨 위 `---` 사이의 값을 고칩니다.
- 각 `## 제목`이 양식의 한 행(기획의도·역할분담·프로젝트 내용·기대효과 및 활용방안)이 됩니다.
- 양식 조건은 "2쪽 이내"입니다. 내용을 추가한 뒤에는 쪽수를 꼭 확인하세요.
- HWPX는 `tools/templates/plan_form.hwpx`(받은 공식 양식)의 칸에 내용을 채워 만들고, 양식의 글꼴(휴먼명조)과 여백을 그대로 씁니다. 한글에서 열어 2쪽인지 확인하세요.
