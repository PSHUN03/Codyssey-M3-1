## 판정 변경

- 서울 희망두배: 지역 및 올해 접수 기간 반영. 출생연도·군 복무 특례는 별도 확인.
- 학자금대출: 2학기 신청 기간과 실행 기간 구분. 날짜 규칙은 일 단위이며 마감 시각은 본문 확인.
- 근로장려금: 정기·기한 후·반기 접수 기간 지원. 신청 종류별 대상 요건은 별도 확인.
- 가구 소득·자산·학적·납입 이력을 개인 연봉으로 추정하지 않음.
- 추가 13개는 미확인 조건이 남아 있어 프로필만으로 적격을 확정하지 않음.

## 남은 작업

- 청년버팀목·청년보증부월세·햇살론유스 원문 전체 및 예외 재확인.
- 기존 7개 정책의 예외 조건 최종 확인.
- PM 독립 검수 질문 확보. 개발용 40문항은 독립 평가가 아님.
- 실제 API 및 자동화 계정 연결·통합 검증.

## 검증

후속 브랜치 테스트 73개 및 Ruff 통과. 개발용 40문항 Hit@1·Hit@3 100%. 기존 12문항 Hit@1 91.7%, Hit@3 100%. 자체 질문 결과를 일반 질의 정확도로 해석하지 않습니다.
