# DATA-04 주간 체크인

내부 리포트 API와 본인 조회 API, 홈 카드에 직접 연결했습니다. APP_WIRING.patch는 사용하지 않습니다.

- n8n/weekly_checkin.json은 비활성입니다. 일요일 20:00 Asia/Seoul에 준비 → 선점 → Gmail → 완료 기록 순서로 실행합니다.
- n8n SADARI_BASE_URL과 X-Internal-Key Header Auth, Gmail OAuth를 설정해야 합니다. 호스팅은 팀 공용 인스턴스를 제안하며 팀 합의 전입니다.
- 최신 이메일 선택 동의를 선점 시 확인합니다. 비동의 회원은 홈 카드만 제공합니다. 같은 사용자·주차에 하나의 리포트를 생성합니다. 회원 삭제 시 리포트도 삭제합니다.
- 선점 후 실패한 건은 자동 재발송하지 않습니다. Gmail 발송 이력을 확인한 운영자가 처리합니다. 정확히 한 번 전달 보장은 아닙니다.
- 리포트는 저장된 목표·계획을 쓰는 규칙 기반입니다. 실제 납입 기록·진척·위험 계산과 LLM 요약은 아직 연결하지 않았습니다.
- 실제 n8n import·예약·Gmail 발송·배포는 미검증입니다. 보고서 본문과 이메일을 실행 로그에 보관하지 않도록 인스턴스 설정도 확인해야 합니다.
