## 기획의도

**"끊어진 계층 사다리, 첫 칸부터 다시 놓는다."**

같은 청년층 안에서도 순자산 상위 20%와 하위 20%의 격차는 **약 40배**에 이릅니다(국회입법조사처, 2026.7). 출발선의 차이는 '정보'와 '습관'의 차이로 굳어지고, 사회초년생 때의 첫 재무 선택이 이후의 자산 격차를 키웁니다. 청년들이 실제로 겪는 문제는 네 가지입니다.

1. **무엇부터 해야 할지 모른다**: 20대의 '재무목표'(36.1점)·'재무점검'(33.2점) 점수가 2년 새 급락 (한국은행·금감원 「2024 전국민 금융이해력 조사」)
2. **나에게 맞는 혜택을 못 찾는다**: 청년정책을 이용하지 않은 이유 2위가 "찾는 방법을 몰라서"(39.3%) (2026.9 청년 설문)
3. **가입해도 유지하지 못한다**: 청년도약계좌 중도해지율이 8.2%에서 15.9%로 증가 (2023년 말 → 2024년 말)
4. **모을 돈 자체가 없다**: 정책금융상품은 '본인 저축'을 전제로 설계되어, 저축 여력이 부족한 청년일수록 소외됨 (국회입법조사처)

기존 자산관리 앱은 **조회·분석**에, 정책 포털은 **목록 제공**에 머뭅니다. **내 현금흐름 × 청년 정책 × 목표**를 하나의 실행 계획으로 묶고, 그 계획이 무너지지 않도록 **곁에서 계속 코칭하는** 서비스는 찾기 어렵습니다. **사다리**는 AI가 **진단 → 설계 → 혜택 매칭 → 실행 → 유지**까지 함께하는 1:1 재무 코치입니다.

## 프로젝트 내용

**서비스 개요**: 사회초년생(만 19~34세, 취업 0~3년 차)이 5분 질문 카드로 재무 진단을 받고, 월급 배분·청년 혜택·저축 목표가 담긴 **나만의 실행 계획**을 받은 뒤, 매주 AI 코치와 점검하며 계획을 유지하는 반응형 웹 서비스(PWA)

**유저 플로우**: 재무 진단(질문 카드) → 월급 배분 플랜 → 청년 혜택 매칭 → 목표 설정 → AI 코치 상담 → 주간 체크인 → 계획 조정

| 핵심 기능 | 내용 | AI 기술 |
|---|---|---|
| ① 재무 진단 | 한 화면에 질문 하나씩 소득·고정비·부채·거주·재직 형태·목표를 받아 재무 프로필 생성 | 목표 문장 해석(LLM) |
| ② 월급 배분 플랜 | 비상금·저축·생활비 배분과 목표 달성 시뮬레이션 (계산은 코드, 설명은 AI) | Agent + 계산 도구 |
| ③ 청년 혜택 매칭 | 자격 조건 필터와 공식 문서 검색으로 받을 수 있는 혜택·예상 수혜액·신청 방법을 출처·기준일과 함께 제시 | RAG |
| ④ AI 재무 코치 | "이번 달 30만 원 더 써도 될까?" 같은 질문에 내 데이터·정책·금융상품 정보를 도구로 조회해 답변 | AI Agent, Memory |
| ⑤ 소비 분석 | 은행·카드 거래내역 엑셀과 영수증 사진을 올리면 자동 분류해 새는 돈·저축 여력을 찾아줌 | 멀티모달, LLM 분류 |
| ⑥ 주간 체크인 | 목표 진척·적금 납입 위험·이번 주 실천 1가지를 담은 개인화 리포트 자동 발송 | 자동화 워크플로우 |

**기술적 접근**

- **필수 기술 요소 5종 모두 적용**: AI Agent · RAG · Long-term Memory · 자동화 워크플로우 · 멀티모달
- **신뢰성 설계**
  - 금액 계산은 Python 코드가, 해석은 LLM이 맡아 수치 환각을 차단
  - 정책 답변에는 출처와 기준일을 반드시 표기. 청년도약계좌 신규가입 종료(2025.12), 청년미래적금 출시(2026.6)처럼 정책이 자주 바뀌기 때문에 LLM의 사전 지식이 아닌 **최신 공식 문서 기반 RAG가 필수**
  - 개별 투자상품 권유를 막는 가드레일 적용
- **데이터**: 온통청년 청년정책 Open API, 금융감독원 금융상품한눈에 Open API, 정부·공공기관 공식 안내문. 계좌 자동 연동(마이데이터 라이선스 필요) 대신 **사용자가 직접 자료를 올리는 방식**을 쓰며, 계좌번호 등 민감정보는 수집하지 않음
- **기술 스택**: FastAPI + HTML/CSS/JS 단일 서비스(Render) · PostgreSQL · Claude API 도구 호출 Agent · BM25 정책 검색 · n8n
- **신뢰성 확인**: API 키 없이도 동작하는 모의 AI 모드와 자동 테스트·AI 품질 평가셋(검색 정답률, 투자 권유 차단율)으로 개발 중 품질을 측정

**일정 (10/1 ~ 11/8)**: 1주 차 역할 확정·환경 구축·**MVP 배포** → 2~3주 차 역할별 기능 개발(소비 분석·영수증 인식·주간 체크인·정책 데이터 확장) → 4주 차 실사용자 테스트(10명 목표, 10/24~) → 5주 차 피드백 반영·안정화·발표 준비

## 기대효과 및 활용방안

**기대효과**

- **개인**: 첫 월급부터 '무엇을 먼저 할지' 분명한 실행 계획을 세우고, 놓치던 청년 혜택을 찾고, 주간 코칭으로 적금 중도해지를 막음
- **사회**: 정보 접근성 차이가 자산 격차로 이어지는 고리를 완화하고, 청년 자산형성 정책이 '가입'에서 '유지'까지 이어지도록 실효성을 높임
- **정량 목표(사용자 테스트 기준)**: 테스터 1인당 새로 알게 된 혜택 2개 이상 · SUS 사용성 점수 70점 이상 · 재사용 의향 60% 이상

**활용방안 및 발전 가능성**

- **B2G·B2B**: 지자체 청년센터, 대학 취업지원센터, 중소기업 신입사원 복지용 재무코칭 도구로 공급
- **B2C**: 기본 무료에 심화 리포트·연말정산 시뮬레이션 등을 담은 프리미엄 구독 추가 (투자자문 영역은 제외해 규제 리스크 최소화)
- **확장**: 마이데이터 사업자와 제휴해 자동 연동을 붙이고, 신혼부부·청년 자영업자 등으로 대상 확대
