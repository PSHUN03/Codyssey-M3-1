# 영수증 평가 샘플 (PM-07 → AI-02)

영수증 인식(AI-02)의 정확도를 재는 샘플 10장과 정답입니다. 정답은 사람이 영수증을 보고 직접 적습니다.

## 사진 규칙

- 파일 이름은 `r01.jpg`~`r10.jpg` (JPEG 또는 PNG, 5MB 이하)
- **카드번호, 승인번호, 이름, 전화번호, 회원번호, 주소는 사진에서 가린 뒤** 올립니다. 가게 이름, 날짜, 품목, 금액은 남깁니다
- 일부러 섞어 찍습니다: 편의점·카페·식당·마트·온라인 주문 캡처, 구겨진 것 1장, 기울어진 것 1장, 어두운 것 1장

## 정답 형식 (`answers.jsonl`, 한 줄에 한 장)

```json
{"file": "r01.jpg", "date": "2026-10-28", "merchant": "가게 이름", "total": 12500, "items": [{"name": "아메리카노", "amount": 4500}], "note": "기울어짐"}
```

| 필드 | 설명 |
|---|---|
| `file` | 사진 파일 이름 |
| `date` | 결제일 `YYYY-MM-DD`. 안 보이면 `null` |
| `merchant` | 영수증에 적힌 가게 이름 그대로 |
| `total` | 결제 총액(원, 숫자). 안 보이면 `null` |
| `items` | 품목과 금액. 품목이 없는 영수증은 `[]` |
| `note` | 사진 상태 메모 (선택) |

## 채점 기준 (기준선을 잰 뒤 팀이 목표를 정함)

- 총액 일치율: `total`이 정확히 같은 비율. 가장 중요한 지표
- 날짜 일치율, 가게 이름 일치율(공백 무시)
- 금액을 못 읽었을 때 지어내지 않고 `null`로 둔 비율 (AI-02 완료 기준 "추측 금지")
