# 영수증 평가 샘플 (PM-07 → AI-02)

영수증 인식(AI-02)의 정확도를 재는 샘플 10장과 정답입니다.

## 가상 영수증 10장

`r01.jpg`~`r10.jpg`는 [make_receipts.py](make_receipts.py)로 만든 **가상 영수증**입니다. 가게 이름, 사업자번호, 전화번호, 카드번호는 모두 지어낸 값이라 개인정보가 없습니다. 같은 코드로 다시 만들면 같은 이미지가 나옵니다 (`python eval/receipts/make_receipts.py`, Pillow 필요).

| 파일 | 상황 | 확인하려는 것 |
|---|---|---|
| r01 | 편의점, 깨끗함 | 기본 인식 |
| r02 | 카페, 7도 기울어짐 | 회전에 강한지 |
| r03 | 국밥집, 초점 흐림 | 흐린 글씨 |
| r04 | 마트, 품목 8개 | 긴 영수증, 수량 2개 품목 |
| r05 | 빵집, 어두운 조명 | 낮은 밝기 |
| r06 | 분식집, 구겨지고 원근 왜곡 | 접힌 자국과 비틀림 |
| r07 | 세탁소, 합계와 품목 금액이 얼룩으로 가려짐 | **못 읽은 금액을 지어내지 않고 `null`로 두는지** |

모든 영수증에 `9410-12**-****-3456` 형태의 가상 카드번호가 있습니다. 저장 전에 가리는지(AI-02 완료 기준)도 함께 확인합니다.

실제 영수증보다 깔끔하므로 이 셋의 결과는 **"가상 영수증 기준"**이라고 밝힙니다. 팀원이 실제 영수증을 모으면 같은 형식으로 `real_` 접두사를 붙여 추가하고 따로 잽니다.

## 정답 형식 (`answers.jsonl`, 한 줄에 한 장)

```json
{"file": "r01.jpg", "date": "2026-10-28", "merchant": "초록편의점 둔산점", "total": 6150, "items": [{"name": "삼각김밥 참치", "amount": 3000}], "note": "깨끗함", "synthetic": true}
```

| 필드 | 설명 |
|---|---|
| `file` | 사진 파일 이름 |
| `date` | 결제일 `YYYY-MM-DD`. 안 보이면 `null` |
| `merchant` | 영수증에 적힌 가게 이름 그대로 |
| `total` | 최종 결제 총액(원, 숫자). 안 보이면 `null` |
| `items` | 품목과 금액(단가 × 수량). 안 보이는 금액은 `null` |
| `note` | 사진 상태 메모 |
| `synthetic` | 가상 영수증이면 `true` |

## 실제 영수증을 추가할 때

- 파일 이름은 `real_01.jpg`부터 (JPEG 또는 PNG, 5MB 이하)
- **카드번호, 승인번호, 이름, 전화번호, 회원번호, 주소는 사진에서 가린 뒤** 올립니다. 가게 이름, 날짜, 품목, 금액은 남깁니다
- 정답은 사람이 영수증을 보고 직접 적고 `"synthetic": false`로 표시합니다

## 채점 기준 (기준선을 잰 뒤 팀이 목표를 정함)

- 총액 일치율: `total`이 정확히 같은 비율. 가장 중요한 지표
- 날짜 일치율, 가게 이름 일치율(공백 무시)
- 지어내지 않은 비율: 정답이 `null`인 칸을 `null`로 둔 비율 (r07)
- 카드번호 마스킹: 결과에 카드번호 숫자가 그대로 남지 않은 비율
