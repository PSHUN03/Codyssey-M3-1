개인정보처리방침

시행일 2026-09-30 · 사다리 팀(코디세이 AI 네이티브 Final-Project)

사다리는 이용자의 개인정보를 소중히 다루며, 서비스 제공에 꼭 필요한 최소한의 정보만 처리합니다. 이 서비스는 교육 과정의 프로젝트로 운영되는 시범 서비스입니다.

1. 수집하는 항목과 목적

  • 계정 정보: 이메일, 닉네임, 비밀번호(암호화 저장). 회원 식별과 로그인에 씁니다.
  • 재무 진단 정보: 나이, 일하는 형태, 회사 규모, 소득, 고정지출, 대출, 저축액, 거주 지역, 목표. 월급 배분 플랜과 청년 혜택 자격 판정에 씁니다.
  • 대화 정보: AI 코치와 나눈 대화, 답변 평가, AI가 기억한 내용. 맞춤 코칭과 서비스 개선에 씁니다.
  • 수집하지 않는 정보: 실명, 주민등록번호, 계좌·카드번호. 대화 중 입력되면 자동으로 가린 뒤 처리합니다.

2. 보유 기간

회원 탈퇴 시 즉시 삭제합니다. 탈퇴하지 않더라도 프로젝트 종료 후(2026년 12월 31일) 모든 데이터를 삭제합니다.

3. 개인정보의 국외 이전

  • 이전받는 자: Anthropic, PBC (미국), Claude API
  • 이전 항목: AI 답변 생성에 필요한 대화 내용과 재무 진단 정보
  • 이전 시기·방법: AI 기능 이용 시 암호화된 통신(HTTPS)으로 전송
  • 목적과 보유 기간: AI 답변 생성. Anthropic의 API 데이터 정책에 따라 처리되며 모델 학습에 사용되지 않습니다.
  • 국외 이전에 동의하지 않으면 AI 기능을 이용할 수 없습니다.

4. 처리 위탁

  • Render(미국): 서비스 호스팅, 데이터베이스

5. 이용자의 권리

설정 화면에서 언제든지 재무 정보를 수정하고, AI가 기억한 내용을 삭제하고, 동의를 변경하거나 탈퇴할 수 있습니다.

6. 안전성 확보 조치

  • 비밀번호 단방향 암호화(scrypt), 전 구간 HTTPS 통신
  • 민감정보(주민번호·계좌·카드·전화번호) 자동 마스킹
  • API 키 등 비밀값의 코드 저장 금지, 접근 권한 최소화

7. 문의

개인정보 관련 문의는 팀 대표 이메일(제출 전 기재)로 연락해주세요.
